# General complex-task workflow
Use the coordinator's native plan. Retain goal definition, design, tradeoffs and final acceptance with Antigravity by default. Delegate bounded substantial implementation, debugging, tests, batch processing, data analysis and artifact generation to Codex if its capabilities fit. User choices override defaults.

Identify real dependencies and approval gates. Delegate a full module or coherent deliverable including tests when possible. Split only when outputs become inputs to a different task, a decision is unresolved, permissions differ, or concurrent edits would conflict. Avoid handing off individual commands or repeatedly switching executors for routine fixes.

A small task can stay native; an explicit Codex request still takes precedence if feasible. For exploratory tasks, specify the question and expected evidence rather than forcing a premature implementation plan. Reassess the native plan after blockers or changed goals. Verify outputs rather than trusting completion claims.
