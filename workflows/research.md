# Research routing guidance
Use the coordinator's native plan; this guide selects handoff boundaries.

- Antigravity: idea discussion, question formulation, hypothesis, research direction, experiment design, scientific interpretation, paper narrative and decisions.
- Codex: scoped literature retrieval and extraction (when search and network tools are available), implementation, tests, authorized experiment runs, reproducible statistics, plotting from verified data, LaTeX and formatting.
- Manuscript drafting and peer review: choose by task, requested skill, available evidence and user preference; default to Antigravity when uncertain. Offer independent review when useful.
- User explicit executor choice overrides these defaults.

Confirm consequential research decisions before implementation when unresolved. Pass agreed protocol, input data, relevant references, output paths, seeds and acceptance criteria. Protect raw data. Never fabricate results or references. Distinguish hypotheses, measurements and interpretations. Check citation identifiers and source provenance. Treat failed experiments as results; do not silently change methods. Verify figures against source data and archive reproducible scripts. Batch cohesive implementation, testing and plotting tasks when dependencies permit.
