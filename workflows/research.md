# Research workflow
Use native planning to track the scientific question, current evidence and next decision. Apply these defaults only at the relevant task boundary.

| Activity | Default owner |
|---|---|
| Idea discussion, hypothesis, theory, research direction | Antigravity |
| Scoped literature retrieval, extraction and evidence table | Codex, if search access is available |
| Research gap interpretation and novelty judgment | Antigravity |
| Experimental design, controls and evaluation metrics | Antigravity |
| Agreed experiment implementation, tests and authorized runs | Codex |
| Reproducible data processing and statistics | Codex |
| Scientific interpretation and next experiment decisions | Antigravity |
| Figure narrative and visual requirements | Antigravity |
| Plot implementation from verified data | Codex |
| Paper narrative and contribution structure | Antigravity |
| Manuscript drafting and peer review | Select dynamically; native when uncertain |
| LaTeX, bibliography and formatting | Codex |

User executor choices take precedence. Skills supply professional methodology independently of executor. Do not force a linear lifecycle: iterate based on evidence.

Handoff gates: research direction scoped before systematic retrieval; protocol agreed before implementation; verified data available before plotting results; evidence available before claims. Preliminary exploratory work can be delegated when clearly labeled and authorized.

Pass the agreed protocol, actual data paths, relevant references, seeds, environment constraints, output paths and acceptance criteria. Preserve raw data and report failed experiments. Never invent results or citations. Verify citation provenance, figures against source data, and reproducibility. Keep implementation and tests together when feasible; return consequential scientific choices to the coordinator.
